# Explainable-Crack-Assessment-LLM
Source code and demo dataset for the paper:

**"Explainable Multimodal Crack Assessment Framework for Pavement Infrastructure Using Large Language Models"**
This repository provides the source code and a representative demo dataset for an explainable multimodal pavement crack assessment framework using large language models (LLMs). The framework integrates pavement crack image processing, geometric feature reconstruction, LLM-based semantic reasoning, and engineering interpretation to support intelligent pavement infrastructure assessment.

## Framework Overview
The proposed framework consists of three sequential modules:

### A1. Crack Image Processing and Feature Extraction (MATLAB)
This module performs pavement crack image processing and extracts geometric and morphological features from crack images, including crack boundaries, centerlines, and structural characteristics.

### A2. Large Language Model-based Crack Assessment (Python)
This module constructs structured crack information and interacts with large language models for semantic analysis, engineering interpretation, and diagnostic assessment of pavement cracks.

### A3. Crack Geometry Visualization and Result Generation (MATLAB)
This module generates visualization results of crack geometry and integrates the assessment information for explainable pavement condition analysis.
